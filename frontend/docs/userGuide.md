## Usando o MarketAlert

### 1. Fazer Login

Ao acessar o sistema, você verá a tela de login. Insira seu email e senha para entrar.

- Clique em **"Entrar"** para acessar o dashboard
- Se não tiver conta, crie uma no nosso portal de autenticação

### 2. Dashboard - Visão Geral

Após fazer login, você chegará ao **Dashboard**, que mostra:

- **Total de Produtos:** Quantos produtos você está monitorando
- **Alertas Ativos:** Quantos alertas precisam de sua atenção
- **Preços OK:** Quantos produtos têm preços competitivos
- **Economia Potencial:** Quanto você pode economizar ajustando preços

Você também verá uma seção de **"Alertas Urgentes"** com recomendações imediatas.

### 3. Gerenciar Produtos

Clique na aba **"Produtos"** para ver todos os seus produtos monitorados.

Para cada produto, você pode:

- Ver o **nome do produto** e seu **status** (Alerta ou OK)
- Comparar seu **preço atual** com o **preço alvo**
- Ver quantos **concorrentes** estão sendo monitorados
- Clicar em **"Ver Anúncio"** para abrir seu produto no Mercado Livre
- Clicar em **"Ver Concorrentes"** para comparar preços com a concorrência

### 4. Adicionar Novo Produto

Clique na aba **"Adicionar"** para monitorar um novo produto.

Preencha os campos:

- **Nome do Produto:** Ex: "Farol Uno Mille Fire"
- **URL do Seu Produto:** Cole o link do seu anúncio no Mercado Livre
- **Preço Alvo (R$):** O preço que você quer manter como referência
- **URL do Concorrente (Opcional):** Link de um concorrente para comparação

Clique em **"Adicionar Produto"** para começar o monitoramento.

### 5. Visualizar Concorrentes

Na página de produtos, clique em **"Ver Concorrentes"** para um produto específico.

Você verá:

- **Nome do concorrente**
- **Preço atual** do concorrente
- **Última atualização** dos dados
- Botão para **"Ver Anúncio do Concorrente"** no Mercado Livre

### 6. Gerenciar Alertas

Clique na aba **"Alertas"** (ícone de sino no header) para ver todos os seus alertas.

Os alertas são separados em:

- **Não Lidos:** Alertas novos que precisam de atenção
- **Lidos:** Alertas que você já visualizou

Para cada alerta, você pode:

- Clicar no **ícone de verificação** para marcar como lido
- Clicar no **ícone de lixeira** para deletar o alerta

### 7. Configurações da Conta

Clique no **ícone de usuário** no canto superior direito e selecione **"Configurações"**.

Nesta página você pode:

- Ver seu **email** e informações da conta
- Acessar opções de **segurança**
- Fazer **logout** da sua conta
